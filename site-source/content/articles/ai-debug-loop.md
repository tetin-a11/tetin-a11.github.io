## 「動きません」だけではAIも直せない

エラーが出たら、すぐにコード全体を作り直させないのがコツです。まず状況を固定します。

1. エラー全文
2. エラーが出た操作
3. 直前に変えた場所
4. 本来どう動いてほしいか

## 修理用プロンプト

```text
次のエラーを、原因候補を広げすぎずに調査してください。
まず再現条件を整理し、最も可能性が高い原因を1つ選んでください。
修正は差分を小さくし、確認手順も書いてください。
```

## 失敗も成果物にする

直ったコードだけを残すと、次に同じ場所で詰まります。「症状 → 原因 → 試した修正 → 結果」の順で短く記録すると、そのまま記事にも次回のAIへの入力にもなります。

> LAB NOTE: AIが自信満々でも、修正後の再現テストは人間の仕事です。
